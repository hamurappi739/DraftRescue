# DraftRescue — UI Copy Baseline

Status: initial English product copy for implementation consistency.

The application may be localized later. Do not build a localization framework prematurely during Phase 0.

## Recovery

Window/title:
- `DraftRescue`

Page subtitle:
- `Recoverable drafts`

Empty title:
- `Nothing to recover`

Empty body:
- `Recoverable drafts will appear here when DraftRescue can safely keep one.`

Privacy reassurance:
- `Drafts stay on this PC and expire automatically.`

Actions:
- `Restore`
- `Preview`
- `Copy`
- `Discard`

Restore success:
- `Draft restored.`

Copy feedback:
- `Copied.`

Safe-match failure:
- `The original field could not be matched safely.`

Manual fallback:
- `You can still preview or copy this draft.`

Expired:
- `This draft has expired.`

## Preview

Title:
- `Draft preview`

- `Discard all`

## Notification

Title:
- `Draft available`

Body pattern:
- `DraftRescue found recoverable text from {ApplicationName}.`

Action:
- `Open DraftRescue`

Never include draft text in notification content.
